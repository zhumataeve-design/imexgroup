# IMEX GROUP — 10 лет

Сайт находится в каталоге dist.

## Подключение Google Sheets

Для приёма ответов используется привязанный к этой таблице Apps Script в режиме `@OnlyCurrentDoc`.
Веб-приложение выполняется от имени владельца и принимает ответы от всех гостей, но имеет доступ
только к таблице, в которой оно создано. Endpoint указан в dist/config.js.
